# FPGA_128x_interp_filter
Design of a 128x High-Order Digital Interpolation Filter Based on the XC7A35T FPGA
Overall plan: Implement a 128x audio digital interpolation filter that converts 44.1 kHz, 24-bit signed PCM input to 5.6448 MHz, 24-bit output. The interpolation ratio is decomposed into 2×2×2×16: Stage 0 and two levels of Halfband FIR are sequentially completed for anti-image filtering, a 31-tap compensation FIR corrects the CIC passband droop at the 8Fs low-speed end, and finally, a third-order CIC with R=16, N=3, M=1 completes the high-ratio interpolation, keeping the main multiplication operations at a lower sampling rate.
Structural innovation 1: Stage 0, Halfband 1, and Halfband 2 no longer each occupy a separate set of multipliers and adders. Instead, they share a single MAC data path through task suspension, context latching, and the fixed priority order of HB2 > HB1 > Stage 0. The historical samples of each level are saved using a circular dual-read LUTRAM, and the DSP occupation is compressed to 1 for the three-level FIR.
Structural innovation 2: The compensation FIR is moved from the high sampling rate output end of the CIC to the 8Fs input end, and the coefficients are redesigned for the current CIC response. The 31 symmetric taps are folded into 16 multiplications and additions, completed by the second MAC sequence, with the DSP occupation reduced to 1; an elastic FIFO with a depth of 8 is set between the compensator and the CIC to absorb the deviation between the completion time of the calculation and the fixed sampling period of the CIC.
Joint word length optimization: MATLAB jointly searches for coefficients, accumulators, and inter-stage sample bit widths under passband, stopband, linear phase, and overflow constraints. Finally, Stage 0 is 16/41 bit, Halfband is 11/31 bit, CIC compensation is 10/30 bit, and inter-stage data is 19/19/19/18/18 bit; the external PCM interface still maintains 24 bit, and coefficient MEM, Golden data, and RTL parameter header files are automatically generated.
Indicators and verification: Passband: 10Hz - 20kHz, passband ripple ≤ 0.022178 dB, stopband attenuation ≥ 74.656824 dB, transition band: 20kHz - 20.175kHz, achieve strict linear phase, the board-level is observed simultaneously through ILA for output, counting, etc.
